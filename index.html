Reticulum ESP-NOW Firmware Flasher

Flash firmware to ESP32 boards via USB from your browser (Chrome/Edge only)

1 Connect Board

Plug your ESP32 board into USB. Some boards require holding BOOT while pressing RESET to enter download mode.

2 Select Firmware

Choose the .bin firmware file for your board.

3 Flash

Log

Web Serial API is required. Supported browsers: Chrome 89+, Edge 89+, Opera 76+. Firefox and Safari are NOT supported.
